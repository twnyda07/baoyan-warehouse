# 寶嚴禪寺・寶嚴山 倉庫管理系統（常住內部）

本 repo 只存放一個**加密後**的單頁網站。`index.html` 是雙入口密碼閘：

- **使用者入口** — 各據點執事、志工、法師：申請物料、查代碼、看辦法、填 WH-F01～F12 表單、運送與交通工具。
- **管理者入口** — 倉儲管理、主管、採購、財務、稽核：審核路徑與判斷準則、平行照會、物流排程與併運試算、代碼治理、盤點、稽核檢核。

前台與後台各是一份獨立密文，**各自用不同密碼**以 AES-256-GCM 加密（金鑰由 PBKDF2-SHA256
310,000 次推導）。拿使用者密碼解不開後台密文——後台內容不會外洩。原始文件與建置腳本不在此 repo。

網站不含任何個人姓名，亦不對外公開、不被搜尋收錄（`noindex,nofollow`）。
